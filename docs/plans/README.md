# Исторические планы и design notes

> Audience: **historical-only surface**. Это исторические документы, а не канонический маршрут по текущему продукту. За актуальной картой документации возвращайтесь в [`docs/README.md`](../README.md).

Эта директория хранит design/proof notes, которые объясняют, как репозиторий пришёл к текущим решениям. Они полезны для исторического контекста и ретроспектив, но не должны заменять актуальные guide-level docs.

## Куда вернуться за текущим owner map

- [`../README.md`](../README.md) — актуальная карта документации и точка возврата из historical surfaces.
- [`../reference/README.md`](../reference/README.md) — reference stack по поддержке, совместимости, артефактам и upgrade rail.
- [`../requirements.md`](../requirements.md) — текущий inventory требований, если нужно сверить историю с нынешними границами.
