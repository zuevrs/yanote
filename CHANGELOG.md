# Changelog

Все заметные **user-facing** изменения Yanote фиксируются здесь в дополнение к GitHub Releases.

## Как читать этот файл

- Авторитетная публичная версия релиза определяется подписанными Git-тегами `vMAJOR.MINOR.PATCH` и страницей GitHub Releases.
- Этот файл — curated change log для пользователей и интеграторов, а не полный git log.
- Формат секций остаётся стабильным: `Added`, `Changed`, `Fixed`, `Deprecated`, `Removed`, `Security`.
- Исторические релизы, выпущенные до появления этого файла, по-прежнему смотрите в https://github.com/zuevrs/yanote/releases
